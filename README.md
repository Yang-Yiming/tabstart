# tabstart

A personal browser start page & launchpad dashboard for your new tab.

## Tech Stack

- React 19 + TypeScript + Vite
- Tailwind CSS 3
- react-grid-layout
- Lucide Icons

## Getting Started

```bash
bun install
bun run dev
```

## Build

```bash
bun run build   # outputs to dist/
bun run preview # preview the build
```
